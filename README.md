## 💻 Local Setup

Clone and run locally in any browser or with Node.js:

```bash
# Clone the repository
git clone https://github.com/Sesuraj15/portfolio.git

# Navigate to directory
cd portfolio

# Run the local server
node server.js
```

Visit `http://localhost:3000` in your web browser.
